# 契约测试（讲师提供，不许改）

这里的测试检查的是**契约**：每个模块对外长什么样、必须做到什么、不允许做什么。
内部怎么写不管——你的实现和别人不一样没关系，这里全绿就算对。

- 测试不通过：改你自己的代码，不要改测试（`docs/工程规范.md` 第 11.1 条）。
- 测试只读 `signal_insight`。要写库的测试都在临时库 `test_course_xxx` 里跑，跑完连库删掉。
- 标着“需要数据”的测试从 `signal_insight` 复制 `ods_` 表到临时库再跑，不依赖、也不改动你自己建的表；
  连不上 MySQL 时它们会被跳过，原因列在输出的最后。
- 运行：先在终端载入 `.env.ps1`（`. .\.env.ps1`），再在项目根目录 `python -m pytest tests/contract -q`。
